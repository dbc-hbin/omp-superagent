# omp-superagent 0.1.3

- Prepare the managed extension from `omp-superkit` and accept both the new
  `omp-superkit` and legacy `omp-ulw` package identifiers. Upgrade Superagent
  before relying on the renamed package.
- Show the configured OMP profile's account quotas and reset times with the
  messenger `/usage` control, without starting a model turn.
- Schedule one-time or recurring requests through HEAD's native cron tool.
- Surface stalled lane follow-ups and let the operator resolve uncertain inputs
  without replaying them.
- Follow OMP's native checkout policy for independent editing lanes. Use
  `ovnfs` when the host requires it unless the operator explicitly requests
  Git worktrees.

## Install or upgrade

Installation requires Git and Bun >= 1.4.4. Running a Host also requires a
compatible stock OMP executable and local Unix sockets.

```sh
bun add --global --trust omp-superagent@0.1.3
omp-sa --help
```

Alternatively, run `npm install --global omp-superagent@0.1.3` with Bun on
`PATH`. Keep lifecycle scripts enabled to prepare the managed extension.
Installation does not start a bot or replace a running Host. If downloading
from GitHub instead, verify the `.tgz` against its `.sha256` before installing.

Release CI uses stock OMP on Linux and macOS. It does not verify live messenger
accounts, provider calls, or native TUI attachment. See the
[operations guide](https://github.com/dbc-hbin/omp-superagent/blob/v0.1.3/docs/OPERATIONS.md).
