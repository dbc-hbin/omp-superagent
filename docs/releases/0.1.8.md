# omp-superagent 0.1.8

- **Control the Discord bot’s online indicator from chat.** Ask the bot to stay online, show its current presence, or turn the indicator off. Turning it off requests invisible without disconnecting the bot. The response distinguishes the requested setting from the value written on the current connection; neither proves what a remote user sees. Slack Socket Mode bots and Telegram bots cannot use this control.
- **Watch a PR or CI from the conversation that needs the result.** Give HEAD a GitHub PR URL or `owner/repo#number`. Checks are sampled every five minutes unless you specify an interval. The first read establishes a baseline; ask for status to see it. Later current-head success or failure goes to the registering conversation, not another channel watching the same PR. Observation never merges a PR or retries CI.
- **Watch a managed lane without changing its work.** Ask to be notified about its progress, a recorded hold or failure, or its closure. Stop notifications without pausing or cancelling the lane. Silence is not reported as a stall.
- **Shorter CI.** The release gate runs the SDK-matched stock OMP on Ubuntu and macOS. OMP 18 remains available for manual compatibility checks; all four native package install checks remain required.

Upgrading from npm **0.1.6** also includes the [0.1.7 changes](https://github.com/dbc-hbin/omp-superagent/blob/v0.1.8/docs/releases/0.1.7.md): enrolled SSH workers, opt-in Discord addressing, and SUPER workflows. The `v0.1.7` tag was retained but its publication was cancelled.

## Install or upgrade

```sh
bun add --global --trust omp-superagent@0.1.8
omp-sa --help
```

Alternatively, use `npm install --global omp-superagent@0.1.8` with Bun 1.4.4 or later on `PATH`. Installation does not start a bot. Running managed sessions requires a separately installed OMP.
